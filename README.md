# DevWebCamp

Este proyecto es una plataforma de conferencias desarrollada en PHP y MVC puro.

## 🚀 Características

- Registro y autenticación de usuarios
- Área de administración para gestionar ponentes, eventos y conferencias
- Pago a través de PayPal (modo sandbox)
- Envío de correos con confirmación
- Diseño responsive

## 🛠️ Tecnologías

- PHP 8.3
- JavaScript
- MySQL
- Composer
- MVC personalizado

## 📦 Instalación

1. Clona este repositorio:

   ```bash
   git clone https://github.com/ErikChable/DevWebCamp.git
   cd DevWebCamp
   ```
2. Instala las dependencias de Composer:
   ```bash
   composer install
    ```
3. Configura tu base de datos en el archivo .env
4. Realiza las configuraciones necesarias en tu servidor y asegúrate de que el servidor tenga soporte para PHP 8.3 y MySQL.
